# BARNES Moscow — каталог недвижимости

Статическая верстка каталога городской недвижимости Москвы по мотивам страницы BARNES Moscow.

## Страницы

- `index.html` — карта объектов и фильтры.
- `listing.html` — листинг недвижимости с быстрыми фильтрами.

Страницы работают без сборки и используют локальные изображения и шрифты из `assets/`.
